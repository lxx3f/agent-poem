# api模块
编写提供给前端交互的API，负责根据schema封装service层返回的数据

# LLM模块
提供LLM服务，包括构建pormpt

# schema
规定API层传入和传出的数据结构

# service
负责具体的业务处理逻辑，要求传入和传出的都是具体数据类型，不要过度封装

## mysql_service
提供数据库基本操作，不进行安全检查（交给具体的业务服务处理）

## user_service
提供用户相关业务操作，并进行安全检查

## potery_service
提供数据库诗词查询服务



# 业务逻辑
agent负责提供system prompt模版以及LLM配置。
agent run的流程：
1. 感知：获取用户输入和历史信息，以及agent的记忆数据
2. loop：循环执行以下步骤
    - 构建prompt（包含系统prompt，用户输入，历史信息，记忆数据，动作执行结果）
    - 调用LLM
    - 解析结果
    - 执行动作（包括更新记忆数据，查询知识库，输出结果给用户等）
