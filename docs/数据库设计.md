# 数据库设计

## 数据库基本信息
- **数据库名称**: shiyun_db
- **字符集**: utf8mb4
- **排序规则**: utf8mb4_unicode_ci

## 1. writer（作者表）
存储古代诗词作者信息

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | INT(11) | PRIMARY KEY, AUTO_INCREMENT | 作者ID |
| name | VARCHAR(50) | NOT NULL, UNIQUE | 作者姓名 |
| dynasty | VARCHAR(20) | DEFAULT '' | 朝代 |
| intro | TEXT | NULL | 作者简介 |
| detail_intro | TEXT | NULL | 作者详细介绍 |
| create_at | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |

**索引**:
- 主键: id
- 唯一索引: uk_writer_name (name)

**默认数据**:
- id=1, name='佚名', dynasty='', intro='作者信息不详'

## 2. poetry（诗词表）
存储诗词作品信息

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | INT(11) | PRIMARY KEY, AUTO_INCREMENT | 诗词ID |
| title | VARCHAR(100) | NOT NULL | 诗词标题 |
| dynasty | VARCHAR(20) | DEFAULT '' | 朝代 |
| writer_id | INT(11) | NOT NULL, DEFAULT 1 | 作者ID，外键关联writer表 |
| keywords | VARCHAR(200) | DEFAULT '' | 关键词 |
| milvus_id | VARCHAR(50) | DEFAULT '' | Milvus向量ID |
| content | TEXT | NOT NULL | 诗词内容 |
| connotation | TEXT | NULL | 注释 |
| translation | TEXT | NULL | 译文 |
| remark | TEXT | NULL | 赏析 |
| create_at | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |

**索引**:
- 主键: id
- 普通索引: idx_writer_id (writer_id), idx_keywords (keywords)
- 外键约束: fk_poetry_writer (writer_id → writer.id)

**默认数据**:
- id=1, title='佚名', content='此诗词暂无具体内容。', writer_id=1

## 3. sentence（诗句表）
存储诗句信息，用于分句检索

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | INT(11) | PRIMARY KEY, AUTO_INCREMENT | 诗句ID |
| content | VARCHAR(200) | NOT NULL | 诗句内容 |
| poetry_id | INT(11) | NOT NULL, DEFAULT 1 | 关联诗词ID，外键关联poetry表 |
| create_at | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |

**索引**:
- 主键: id
- 普通索引: idx_poetry_id (poetry_id), idx_content (content)
- 外键约束: fk_sentence_poetry (poetry_id → poetry.id)

## 4. users（用户表）
存储系统用户信息

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | BIGINT | PRIMARY KEY, AUTO_INCREMENT | 用户ID |
| email | VARCHAR(128) | NOT NULL, UNIQUE | 登录邮箱 |
| password_hash | VARCHAR(255) | NOT NULL | 密码哈希 |
| username | VARCHAR(64) | NULL | 用户名/昵称 |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

**索引**:
- 主键: id
- 唯一索引: email

## 5. agents（智能体表）
存储AI智能体配置信息

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | BIGINT | PRIMARY KEY, AUTO_INCREMENT | Agent ID |
| name | VARCHAR(64) | NOT NULL | Agent 名称（展示用） |
| code | VARCHAR(64) | NOT NULL, UNIQUE | Agent 唯一标识 |
| description | VARCHAR(255) | NULL | Agent 描述 |
| workflow_key | VARCHAR(64) | NOT NULL | 绑定的 workflow key |
| system_prompt | TEXT | NOT NULL | Agent 规则 Prompt（system role） |
| parameters | JSON | NULL | workflow 参数配置 |
| llm_config | JSON | NULL | 模型配置 |
| is_active | TINYINT | DEFAULT 1 | 是否启用 |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

**索引**:
- 主键: id
- 唯一索引: code

**默认数据**:
系统预置4个智能体：
1. poetry_chat_v1 - 诗词问答助手
2. poetry_semantic_search_v1 - 诗词语义搜索
3. feihualing_v1 - 飞花令
4. poetry_chain_v1 - 诗词接龙

## 6. conversations（会话表）
存储用户与智能体的对话会话

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | BIGINT | PRIMARY KEY, AUTO_INCREMENT | 会话ID |
| user_id | BIGINT | NOT NULL | 所属用户ID，外键关联users表 |
| title | VARCHAR(128) | NULL | 会话标题 |
| agent_id | BIGINT | NOT NULL | 所属agentID，外键关联agents表 |
| memory_data | JSON | NULL | 短期记忆数据 |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

**索引**:
- 主键: id
- 外键约束: 
  - fk_conversations_users (user_id → users.id, ON DELETE CASCADE)
  - fk_conversations_agents (agent_id → agents.id, ON DELETE RESTRICT)

## 7. messages（消息表）
存储会话中的具体消息

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | BIGINT | PRIMARY KEY, AUTO_INCREMENT | 消息ID |
| conversation_id | BIGINT | NOT NULL | 所属会话ID，外键关联conversations表 |
| role | ENUM('user', 'assistant', 'system') | NOT NULL | 消息角色 |
| content | TEXT | NOT NULL | 消息内容 |
| status | ENUM('pending', 'done', 'failed') | NOT NULL | 消息状态 |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |

**索引**:
- 主键: id
- 外键约束: fk_messages_conversations (conversation_id → conversations.id, ON DELETE CASCADE)

## 8. agent_user_memory（Agent用户记忆表）
存储Agent与用户的长期记忆关联

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | BIGINT | PRIMARY KEY, AUTO_INCREMENT | 主键ID |
| agent_id | BIGINT | NOT NULL | Agent ID，外键关联agents表 |
| user_id | BIGINT | NOT NULL | 用户ID，外键关联users表 |
| memory_data | JSON | NULL | 长期记忆数据 |
| last_interaction_time | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 最后交互时间 |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

**索引**:
- 主键: id
- 唯一索引: uk_agent_user (agent_id, user_id)
- 外键约束:
  - fk_agent_user_memory_agents (agent_id → agents.id, ON DELETE CASCADE)
  - fk_agent_user_memory_users (user_id → users.id, ON DELETE CASCADE)

## 外键关系图

```
users (1) ←→ (∞) conversations (1) ←→ (∞) messages
   ↑                    ↓
   |                 agents
   |                    ↓
   └─→ agent_user_memory ←┘

writer (1) ←→ (∞) poetry (1) ←→ (∞) sentence
```

## 数据库约束说明

### 外键约束
- **级联删除**: users → conversations, conversations → messages
- **限制删除**: writer → poetry, poetry → sentence, agents → conversations
- **设置为空**: 无

### 默认值设置
- 时间字段统一使用 `CURRENT_TIMESTAMP`
- 更新时间字段使用 `CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP`
- 关联字段设置合理的默认值（如writer_id默认为1-佚名）

### 字符集统一
所有表均使用 `utf8mb4` 字符集，支持完整的中文字符和表情符号存储。
